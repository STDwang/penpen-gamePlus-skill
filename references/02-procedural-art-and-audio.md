# 02 · 零素材程序化美术与物理驱动音频规范

零外部素材并不等于“简陋几何体 + 刺眼霓虹色 + 蜂鸣器音效”。本规范总结了让纯代码生成的画面与声音达到独立游戏质感的核心配方。

---

## 一、程序化美术的 6 条“高级感”铁律

### 1. 光线先行：用低仰角光与亮度压制取代“贴图堆砌”
AI 生成的 3D/2D 场景最常见的廉价感是“顶光均匀照亮 + 高饱和塑料色 + 前景过曝死白”。必须从第一天就定死光学锚点：
- **低仰角主光（黄金逆光/侧逆光）**：默认开局采用低仰角太阳/主光源（约 `0.18–0.32 rad`），让地形起伏、边缘轮廓、扬起的粒子/水雾/尘埃获得强烈的背光散射（Rim / Backlight），成为全画面除光源外最亮的层次。
- **压住前景中调，留出高光动态范围**：即使主材质是雪、沙、云、白墙，前景表面通过曝光控制与微阴影压在中等亮度（`L* 60–72`），绝不烧成纯白 `1.0`；把 `0.85–1.0+` 的高光通道留给太阳眩光、逆光粒子、镜面闪烁与关键视觉引导物。
- **三层大气透视**：近景（高对比、清晰微法线）、中景（轻薄空气雾、主色调融合）、远景（低对比冷/暖雾化剪影，脚部融入云海或地平线雾），严禁远景锐利得像贴在天空上的贴纸。

### 2. 昼夜/情绪循环与自动曝光
- 哪怕是单局几分钟的游戏，也建议引入**可配置的动态时间/光影演进**（例如 1 真实秒 = 1 分钟，或随关卡推进从晴午 → 日落 → 暮色 → 极光/霓虹夜平滑过渡）。
- **分时段差异化曝光**：日落时主动收紧曝光保住天空渐变色彩；夜晚压低整体亮度并将环境补光向中性灰拉回约 1/3，靠主角随身光源（头灯/车灯/提灯）在身前照出一片清晰光池。

### 3. 程序化几何与材质：绝不用光秃秃的基础球和方盒
- **角色与生物**：优先采用**距离场（SDF）+ 表面网（Surface Nets / Marching Cubes）**或**沿骨骼放样的超椭圆截面（Lofted Superellipse）**生成有机圆润体态，配合关节蒙皮与物理摆动（围巾、衣角、飘带）。
- **自然物与建筑**：树木/岩石/礁石使用分形噪声扰动 + 分层伞盖/斜面体块，配合顶点色/高度混合（顶部积雪/受光暖、底部阴暗冷）与 GPU Instancing 批量绘制。
- **程序烘焙贴图**：启动时用 CPU/Worker 或离屏 Pass 一次性烘焙多频噪声（Value/Simplex/Worley）、微表面法线、粗糙度与微闪烁（Glitter）贴图，全流程零外部 PNG。

### 4. 环境交互：让世界对玩家“留下痕迹”
高级感的核心来源之一是**玩家与环境的双向反馈**：
- **地面/介质痕迹**：在玩家周围维护一个滚动局部 RenderTarget（如 `512×512` 滚动轨迹图），记录压痕、胎印、水波、脚印，并在地形着色器中同时驱动法线凹陷与颜色明暗变化。
- **物理受光粒子**：扬尘/雪雾/水花不能只是平淡的半透明圆点，必须参与主光源的逆光散射与阴影，并叠加少量细碎高光颗粒（Grains/Glitter）增加速度感。
- **镜头遮挡优雅避让**：当树木、柱子、拱门恰好挡在相机与主角之间时，不要硬切或把主角挡死——在透明 Pass 中让遮挡物在 `~0.16s` 内平滑淡出，但**保留它的地面投影**，保持空间真实感。

### 5. 后处理与数值安全红线
- **HDR + Filmic / ACES 色调映射 + 多级 Bloom**：高光自然溢出而非生硬发光贴片。
- **半浮点（RGBA16F）防溢出铁律**：任何叠加写入的粒子/雾效/体积光 Buffer，单粒子权重必须封顶，合成采样前必须 `clamp` 有限值，防止大量粒子重叠导致 `Inf/NaN` 在屏幕上炸出永久“黑洞”。
- **速度感微效应**：随速度渐进增强的边缘动态模糊（采样数按拖影长度自适应，不空耗 GPU）、极轻的镜头眩光与风压微颤——并确保在暂停、拍照和低画质档位可控关闭。

### 6. 视觉决策必须入账
上述所有关键参数（光仰角、曝光值、雾色、遮挡淡出时长、粒子上限）必须写入项目根目录的 `DESIGN_INVARIANTS.md`，防止后续迭代被无意破坏。

## 二、零素材物理驱动音频合成规范（Web Audio API）

绝不用廉价的“单一正弦波 beep”应付音效。参考真实物理发声原理，建立**“离线底材 + 实时物理调制”**架构：

### 1. 启动/首次交互时一次性合成底材 Buffer（零音频文件）
利用确定性随机流预生成 3–4 秒的**无缝交叉淡入淡出（Equal-Power Crossfade）**双声道循环底材：
- **独立双通道高斯白噪**：用于清脆摩擦、高频气声、溅射。
- **Kellet 7 阶滤波粉噪（Pink Noise）**：用于风声、海浪、低沉滚动、环境底噪（左右声道独立生成，天然拥有立体声包裹感）。
- **颗粒/质地调制噪声（Sand / Patter）**：在粉噪上叠加速度可控的随机包络，模拟雪粒、砂石、雨滴、路面颗粒感。
- **慢速阵风/起伏控制曲线**：预烘焙平滑多倍频噪声表，驱动风噪双耳独立抖动与镜头微风压（**声画同源**）。

### 2. 连续音轨：每帧由物理状态直接驱动
至少构建 3–4 条始终呼吸、随操作连续变化的物理声部：
1. **速度风声（Wind）**：粉噪经低通滤波器，截止频率与音量随 `speed` 非线性爬升，左右耳受阵风表独立微调；极速时叠一层极细的带通哨音。
2. **介质滑行/行进声（Glide / Surface）**：白噪/颗粒噪经带通，随速度和地面材质（软/硬/湿/空）动态切换中心频率与亮度；腾空时平滑衰减归零。
3. **动作负载/转向切刃声（Action / Edge / Engine）**：根据转向角、侧向加速度、刹车载荷驱动带通增益与声像偏移（例如向右切弯时声音略偏甩出侧），起振短促有力、松手自然回落。
4. **低频细节/环境氛围（Creak / Ambience / Generative Music）**：极低速下的材质微响 + 随速度/高度/昼夜缓慢演进的极简合成器音景（基于五声/利底亚等协和音阶的柔波+卷积/延迟混响，不喧宾夺主）。

### 3. 瞬态音效与工程纪律
- **瞬态事件**：起跳、落地（按垂直冲击速度缩放低频闷响与散落颗粒）、擦碰、通关、UI 轻触，全部按物理强度参数化触发，并加随机微音高偏移防“机关枪效应”。
- **音频安全纪律**：
  - 所有增益与频率变更必须使用 `setTargetAtTime(val, now, tau)` 平滑过渡，严禁直接赋值导致咔嗒爆音（Click/Pop）。
  - 输出末端挂软限幅器/压缩器（`DynamicsCompressorNode`）防止多声部叠加削波失真。
  - 尊重浏览器自动播放策略：首次用户手势时解锁/懒初始化 `AudioContext`；`document.visibilitychange` 切后台自动静音，切回恢复。
